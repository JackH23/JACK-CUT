## Installation Instructions
To install the necessary dependencies, run the following command:

```
pip install -r requirements.txt
```

If you are installing the package via `setup.py`, use the optional `timeline` extra to
pull in the video export dependency:

```
pip install .[timeline]
```

## Usage
To run the application, execute the following command:

```
python src/main.py
```

> **Note:** Timeline export relies on the optional MoviePy dependency. If you see the
> message `MoviePy is required to export timelines`, install it with `pip install moviepy`
> (or include the `timeline` extra shown above) and restart the application.
